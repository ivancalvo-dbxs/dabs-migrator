# Goal

The goal is to get the right YAML skeleton for all the resources located on the resources folder.

# Background

Previously, we generated the first version of the skill but the team noticed that there are inconsistencies on the YAML scheleton.

# How to fix it

## Source of truth

The source of truth for the right skeleton can be found in the file dabs-schema.json located in the root folder. 

For reference, this file can be generated by running the command "databricks bundle schema >> dabs-schema.json"

### Example

On the line 1192 you have the resource.Pipeline schema:

```yaml
"resources.Pipeline": {
                "oneOf": [
                  {
                    "type": "object",
                    "properties": {
                      "allow_duplicate_names": {
                        "description": "If false, deployment will fail if name conflicts with that of another pipeline.",
                        "$ref": "#/$defs/bool"
                      },
                    ....
```

## Claude Task

- Use the source of truth and parse the right skeleton for each resource. Add all the available fields.
- Modify the resource definition on the folder to increase the accuracy of the skill.
